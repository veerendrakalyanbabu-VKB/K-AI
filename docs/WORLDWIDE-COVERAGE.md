# Worldwide coverage update

World flights requests the OpenSky global state endpoint, cached one hour, capped at 12,000 positioned aircraft. It remains a receiver-limited snapshot and can be denied by the provider. Explore flights here requests regional fallback providers; World flights restores global scope. OpenSky calls charge four units against the application's conservative shared daily budget.

Marine now subscribes to the worldwide AIS bounding box. At most 6,000 vessel records are retained and expire after ten minutes. Busy streams can drop reports and free hosting sleep interrupts reception. This is not all ships worldwide.

Active and Starlink OMM catalogs cap at 6,000 records. Positions are calculated, not telemetry. CelesTrak availability and element-age checks apply. Stations/ISS remains selectable.

Displayed icon budgets are geographically distributed. Not every loaded record is drawn; all loaded records remain searchable. Aircraft/vessel glyphs rotate using supplied course; this is not camera-calibrated heading or interpolated motion.

Validated with Python compilation and JavaScript syntax checks. Live upstream coverage requires post-deployment verification.
